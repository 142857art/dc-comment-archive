# 디시 댓글 보관함

PC 디시인사이드에서 내 글의 댓글을 Chrome에 저장하는 확장 프로그램입니다. 원글이 삭제된 뒤에도 이미 저장한 댓글을 보관함에서 읽을 수 있습니다. 현재 버전은 **v0.3.4**이며 Chrome 120 이상이 필요합니다.

## 설치·업데이트

1. [Releases](https://github.com/142857art/dc-comment-archive/releases/latest)에서 배포 ZIP을 받아 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 위치의 `extension` 폴더를 선택합니다.
4. 확장 아이콘을 눌러 설정하고, 이미 열려 있던 디시 페이지를 새로고침합니다.

업데이트할 때는 기존에 설치한 `extension` 폴더의 파일을 교체하고 확장 관리 화면에서 **새로고침**을 누르세요. 보관 자료를 유지하려면 기존 확장을 제거하지 마세요. **전체 JSON 내보내기**로 자료를 별도 저장할 수 있습니다. 기존 설정은 유지되므로, 이전에 확인 간격을 30초로 저장했다면 직접 3초로 바꿔 저장해야 합니다.

30초보다 짧은 확인 간격은 개발자 모드의 **압축해제 설치**에서 지원합니다. 일반 설치에는 Chrome의 최소 30초 예약 실행 제한이 적용됩니다. 실제 실행은 브라우저 상태와 요청 처리에 따라 늦어질 수 있습니다.

## 사용

- **글쓰기에서 선택:** 취소 버튼 왼쪽의 **댓글 백업**을 켠 뒤 글을 등록합니다. 등록에 성공하여 글 번호가 확인되면 감시 대상이 됩니다. 등록 실패·등록 대기·기존 글 수정은 대상 등록으로 처리하지 않습니다.
- **모든 내 글:** 설정에서 **모든 내 글을 백업 대상으로 지정**을 켜면 새 글을 자동 지정하고, 글쓰기의 개별 버튼은 숨깁니다. 기존 글은 방문했을 때 작성자 회원 ID가 설정의 **내 갤로그 ID**와 일치하면 지정합니다. 과거 글 전체를 검색하는 기능은 없습니다.
- **보관함:** 글·댓글을 검색하고 저장 자료를 확인합니다. 전체 JSON 내보내기를 지원하며, 가져오기는 지원하지 않습니다. 보관 삭제는 해당 글의 자료를 삭제하고 감시도 중지합니다.

**내 갤로그 ID**는 `https://gallog.dcinside.com/ID`의 `ID` 부분입니다. 닉네임이나 비밀번호가 아닙니다. 방문한 기존 글의 작성자 판별에 사용하며, 회원 ID가 없는 비회원 글은 기존 글의 자동 판별을 지원하지 않습니다.

## 확인·종료 방식

| 설정 | 기본값 | 범위 |
|---|---|---|
| 확인 간격 | 3초 | 1~3600초 정수 |
| 댓글 수 무변화 시 종료 | 10분 | 1~1440분 정수 |

새로 작성한 글은 주소·제목과 감시 상태만 기록하고 댓글 수 0개로 시작합니다. 등록 직후 댓글을 최초 수집하지 않습니다. 이후 설정한 간격으로 **댓글 API를 직접 조회**하고, 댓글 수가 바뀌면 반환된 댓글을 보관합니다. 방문하여 지정한 기존 글은 첫 확인 때 현재 댓글을 수집합니다. 일반적인 댓글 확인에는 글 본문을 요청하지 않습니다.

디시 웹 알림이나 열어 둔 대상 글의 댓글 수 변경을 감지하면 확인을 앞당깁니다. 이미 진행 중인 수집이 끝나기 전에는 다음 수집을 겹쳐 실행하지 않습니다. 네트워크 오류가 반복되면 확인 간격을 늘립니다.

**10분간 댓글 수 변화가 없으면 감시를 종료**합니다. 댓글 수가 바뀌면 마지막 변화 시각부터 다시 계산합니다. 종료 후에는 알림이 오거나 글을 방문해도 자동 재개하거나 추가 조회하지 않습니다. 팝업의 **확인 중인 글**에서도 즉시 중지할 수 있습니다. 종료·중지는 저장한 댓글을 지우지 않습니다.

Chrome과 네트워크가 사용 가능한 동안에는 디시 탭이 없어도 동작합니다. 절전·브라우저 종료·실행 지연 중에는 수집하지 못하며, Chrome을 다시 실행했을 때 종료 시간이 지났다면 감시를 재개하지 않습니다. 전체 **댓글 백업 사용**을 꺼 둔 동안에도 종료 시간은 흐릅니다.

## 삭제 알림

감시 중 약 30초 간격으로 갤러리 목록에서 글의 존재를 확인합니다. 제한된 범위의 목록에서 대상 번호보다 큰 글과 작은 글이 모두 확인됐는데 대상 글만 없을 때 삭제를 의심합니다. 단순히 다음 페이지로 밀렸거나 확인 범위 밖에 있다는 이유만으로 삭제 처리하지 않습니다.

삭제가 의심되면 글 본문을 한 번 요청합니다. 디시 서버가 해당 글의 명시적인 삭제 응답을 보내야 감시를 끝내고, 디시 페이지 좌하단에 보관함을 여는 알림을 표시합니다. 같은 부재 상태에서는 본문 확인을 반복하지 않으며, 이후 목록에서 글이 다시 확인되면 다음 삭제 의심에 한해 재확인할 수 있습니다. 삭제 의심이 틀렸을 때는 이 확인으로 조회수가 한 번 증가할 수 있습니다.

디시 탭이 없으면 확장 아이콘에 확인하지 않은 삭제 건수 배지를 표시하고, 이후 디시 페이지에서 알림을 표시할 수 있습니다. 운영체제 알림은 사용하지 않습니다. 댓글 API의 댓글 0개 응답, 접근 제한·로그인 화면·통신 실패만으로 삭제 처리하지 않습니다. 감시 종료 후 삭제된 글은 확인하지 않습니다.

## 저장·개인정보

- 자료는 현재 Chrome 프로필의 `chrome.storage.local`에 저장합니다. 별도 서버로 전송하거나 기기 간 동기화하지 않습니다.
- 디시 접근에는 현재 Chrome의 로그인 상태를 이용합니다. 비밀번호·쿠키·작성 중인 글 본문을 보관하지 않습니다.
- 댓글 본문·작성자·표시 시각·답글 관계·관찰한 수정 이력을 보관합니다. 이미지·디시콘 등은 추출 가능한 설명과 URL만 저장하며 파일 자체는 백업하지 않습니다.
- 로컬 저장 용량 제한이 적용됩니다. 필요한 자료를 JSON으로 내보낸 뒤 불필요한 자료를 삭제할 수 있습니다. 확장을 제거하면 로컬 자료도 삭제됩니다.

| 권한 | 용도 |
|---|---|
| `storage` | 설정과 댓글을 로컬에 저장 |
| `alarms` | 대상 글의 백그라운드 확인 예약 |
| `offscreen` | 화면 없는 문서에서 글·댓글 응답 분석 |
| `https://gall.dcinside.com/*` | 디시 글·댓글 조회, 글쓰기 버튼과 삭제 알림 표시 |

## 한계

PC 일반·마이너·미니·인물 갤러리 경로를 지원합니다. 댓글 API와 목록을 이용한 새 확인 방식의 실제 서버 검증은 일반 갤러리에서 수행했습니다. 로그인이 필요한 비공개·비밀글 수집은 검증하지 않았습니다. 모바일 페이지는 지원하지 않습니다. 디시 화면이나 응답 구조가 바뀌면 코드 수정이 필요할 수 있습니다.

확인 사이에 달렸다 삭제된 댓글이나 총수 변화 없이 교체된 댓글은 놓칠 수 있습니다. 저장 전에 삭제된 댓글은 복구할 수 없습니다. 저장한 댓글은 원문에서 사라져도 지우지 않습니다. 감시 대상이 많거나 간격이 짧을수록 요청량이 늘어납니다. 큰 댓글 목록은 한 번에 최대 10페이지씩 수집하고 다음 확인에서 이어갑니다.

목록 확인 범위 밖의 오래된 글이나 목록 응답을 분석하지 못한 글은 삭제 알림이 늦어지거나 누락될 수 있습니다. 본문 요청을 반복하는 기존 방식은 제거했지만, 추가 조회수 0회와 모든 삭제 감지를 보장하지는 않습니다.

## 개발·검증

별도 빌드 없이 `extension` 폴더를 Chrome에 로드합니다. 단위 테스트에는 Node.js 20 이상과 npm이 필요합니다.

```sh
npm ci
npm test
```

자동 테스트가 등록 성공 감지·댓글 수집 응답·대상 상태·화면 동작을 검증합니다. Chrome 155의 별도 프로필에서는 검증용 응답을 사용해 디시 탭 없는 3초·1초 확인, 요청 중복 방지, 삭제 알림과 보관함 연결을 확인했습니다. 일반 갤러리의 공개 글에서 본문 요청 없이 댓글 API로 수집하는 방식과 호출 전후 조회수 유지도 확인했습니다. 로그인한 계정으로 실제 글을 작성하고 삭제하는 전체 과정은 검증하지 않았습니다.

코드 변경 후에는 확장 프로그램을 다시 로드하고 기존 디시 탭도 새로고침하세요.
